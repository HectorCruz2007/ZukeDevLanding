Habilidades

GDScript

Scripting intermedio y avanzado en Godot Engine. Manejo fluido del árbol de escenas (SceneTree), comunicación desacoplada mediante señales (Signals), creación de métodos, vinculación de variables (@export), gestión de nodos de física 2D/3D, máquinas de estados y optimización de llamadas de ciclo de vida (_process, _physics_process).

C++

Programación orientada a objetos y genérica (Plantillas/Templates). Control de memoria eficiente (Stack vs. Heap, Punteros Inteligentes), optimización a bajo nivel, manipulación de la biblioteca estándar (STL) y desarrollo de sistemas de alto rendimiento para lógica de videojuegos y motores.

Java

Dominio de Programación Orientada a Objetos (encapsulamiento, herencia, polimorfismo y abstracción). Manejo de colecciones avanzadas (Collections Framework), control de excepciones, concurrencia/multihilo, gestión automática de memoria y diseño de arquitectura limpia.

Forge

Creación e integración de mods. Registro de contenido personalizado (bloques, ítems, entidades y recetas), gestión del sistema de eventos (EventBus), desarrollo de TileEntities/BlockEntities y sincronización de datos cliente-servidor mediante paquetes NBT.

Figma

Diseño de interfaces (UI/UX) y maquetación de prototipos interactivos. Creación de componentes modulares con variantes y propiedades, maquetación adaptativa mediante Auto Layout, estructuración de Design Systems, wireframes de alta fidelidad y preparación de entregables (handoff) para desarrollo.

Geometry Dash Triggers

Programación visual de eventos dentro del editor de niveles. Control avanzado de triggers mecánicos y visuales (Move, Rotate, Spawn, Toggle, Alpha, Animate), manipulación de grupos e IDs (Group ID, Item ID), variables de conteo y automatización de minijuegos o sistemas complejos.
